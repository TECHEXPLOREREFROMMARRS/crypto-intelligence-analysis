# Crypto Intelligence Analysis

A cryptocurrency analytics platform that tracks whale activity,
market risk indicators, and price predictions using machine learning.

## Features

- Whale transaction detection
- Market risk analytics
- Ethereum blockchain monitoring
- ML-based price prediction
- Interactive dashboard

## Tech Stack

Backend:
- FastAPI
- Python
- SQLite

Machine Learning:
- Scikit-learn
- XGBoost

Frontend:
- React
